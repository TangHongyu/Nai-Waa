# Nai-waa 角色代入

把目标图中的指定人物整体替换为 Nai-waa。角色参考决定“它长什么样”，目标图决定“它在哪里、做什么”。这是参考图驱动的图像编辑流程；每次调用都需要实际传入角色图，不把文字描述或过往聊天记忆当作视觉参考。

## 输入与角色资料

- 本技能已包含角色资料。每次使用先读取 [角色特征与参考图说明](references/character-identity.md)，再查看 `assets/character-reference/nai-waa-three-views.png` 与 `assets/character-reference/nai-waa-3d-reference.png`，路径均相对本技能目录解析。不要依赖最初上传的桌面路径。只有随技能参考图丢失或不可读取时才请用户补充。
- 还需要一张目标图片。若用户只在制作技能，可以先完成角色资料整理，不擅自开始生图；用户要求试替换时再执行。
- 查看每张参考图与目标图；本地图片先通过 `view_image` 查看。三视图主要定义轮廓、比例及各方向结构，三维效果图主要定义体积、材质和配色。三维效果图按图像参考处理，不声称已导入、绑定或驱动三维模型。
- 同一角色的 Na-waa / Nai-waa 写法在此流程中兼容；不据拼写自行构造另一个角色。若用户明确指出它们是不同角色，以用户说明为准。
- 收到角色图后，若当前任务包含建立可复用角色资料，将可访问的原始图像复制到技能的 `assets/character-reference/`，保留原件；在 `references/character-identity.md` 中记录各图的相对路径、视角、用途及可确认的角色特征。只引用真正保存成功的文件，不能把聊天附件标识写成永久本地路径。无法持久保存附件时，请用户提供可访问的本地文件，或明确说明后续需重新附图。
- 角色特征记录包括可见的轮廓、头身比例、五官位置、主辅色、标志性结构、固定服饰配件和材质。保留左右不对称关系，以角色自身左右为准；无法确认的细节保持未确认，不猜测精确色值或被遮挡结构。
- 用户指定的新版设定优先于旧资料；图像互相矛盾且影响替换时，简短询问以哪版为准。资料缺失时不声称已经完成角色绑定。

## 替换规则

1. 区分每张图的用途：角色结构参考、角色材质参考、待编辑目标图。明确指定要替换的主体；只有一个清晰主角时默认替换它，多人且指向不明时询问替换哪一个。
2. 默认整体替换人物的头、身体和四肢，并保留 Nai-waa 的角色比例及标志性服饰。不能只换脸、套头或留下原人物躯干。若用户明确要求换脸、换装或局部替换，按该请求调整。
3. 从原人物继承动作意图、朝向、表情情绪、视线、画面位置及互动关系。按 Nai-waa 的身体结构重建姿势，不能为了贴合人体而拉长角色四肢或改变头身比。保持合理的手持、坐靠、脚底接触及遮挡关系。
4. 保留目标图的画幅、镜头、透视、构图、背景、其他人物、道具与可见文字。仅允许为替换主体修补必要的遮挡背景、接触阴影和局部反射；不要顺带重做画面或添加装饰。
5. 默认融入目标图的画风和光线，同时保留角色轮廓、比例、五官布局、固有色及标志性结构。照片中使用合理体积和环境光；插画中匹配线条和笔触。用户要求保留三维质感时遵从该要求。
6. 当前 Nai-waa 参考没有服饰和配件，默认保留本体外观及奶油色腹部色块；只继承目标人物的动作与必要互动道具。用户要求继承目标服装时再迁移服装，并保留角色身份特征。参考图里的抱腹动作、白底和英文视角标签都不迁移到目标图中。

## 图像编辑

使用可用的内置 `image_gen` 图像编辑工具（当前为 `image_gen.imagegen`，编排接口可能显示为 `image_gen__imagegen`）。不需要用户提供 API Key。工具不可用或失败时如实报告；不自行改用付费 API 或编写替代调用脚本。

每次生成都实际传入目标图及所需角色参考图，并在提示词中逐一标记用途：

- 所有输入均有本地路径时，先查看图片，再通过 `referenced_image_paths` 传入全部所需图像。
- 存在仅在对话中的输入时，仅在最近对话图像能覆盖全部必需输入的情况下，使用最小的 `num_last_images_to_include`（至多 5）。不要同时设置这两个参数。
- 若这两种方式都不能覆盖全部必需输入，请用户重新附上缺失图像；不要只传目标图、遗漏角色参考。参考过多时选用能说明关键结构和材质的最小充分集合。
- 原图有透明通道时保留透明；用户要求透明背景时设置 `transparent_background: true`，否则按原图保留背景。

根据实际输入编写简洁编辑提示，明确图片编号与用途、替换对象、角色特征、动作和需保留区域。例如：

> 将指定目标图中的主角整体替换为角色参考图中的 Nai-waa。三视图用于约束各视角结构、轮廓和身体比例，三维效果图用于约束材质与固有色。严格保留已观察到的角色标志性特征。继承目标人物的动作意图、朝向、视线及与道具的互动，按角色自身结构调整姿势。匹配目标图画风、透视和环境光。保留画幅、背景、其他人物、道具与文字，只修补替换主体周围必要的遮挡和阴影。输出一张完成的场景图，不加入参考图拼贴或额外人物。

不要把例文当作足够的角色资料；将观察到的真实特征补进实际提示词。每轮修正都继续提供角色参考，并重复关键保留要求。

## 检查与交付

- 检查角色轮廓、比例、五官、配色和标志性配件是否符合参考；有无残留的人脸、人体或重复肢体。
- 检查动作、手持道具、视线、落地与遮挡是否成立，背景、其他主体及文字是否发生明显漂移。
- 默认先生成一张。出现明显偏差时进行一次针对主要问题的修正；仍不符合时明确说明偏差并交付可评估结果，避免无限重试。用户要求继续修改时再按反馈迭代。
- 保留原图，结果使用新文件名。按当前工作区规则保存项目交付图，并展示预览、给出可点击文件链接和简短说明；可随图保存实际编辑提示词以便复现。
- 区分“结构检查通过”“已保存参考图”“已完成实图试替换”，只报告实际完成的阶段。图像生成可能改变局部细节，不承诺像素级保留或每次完全一致。

## 典型调用

`使用 $nai-waa-character-replace，把这张图里的人物替换成 Nai-waa，保留动作、背景和构图。`

若已有随技能保存的角色参考，后续只需提供目标图；若参考尚未保存或无法读取，需补齐角色参考图。
